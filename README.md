# ClipHistory

[English](README.en.md)

クリップボードの履歴を残すメニューバーアプリです。

ふつうにコピーするだけで、テキストと画像が履歴に残ります。⇧⌘V で出る一覧から選ぶと、今使っているアプリにそのまま貼れます。iPhone でコピーしたものも、ユニバーサルクリップボードを使っていれば Mac の履歴に残ります。

- macOS 13 以降で動きます（Apple シリコン・Intel）。
- 日本語と英語に対応しています。Mac の言語設定に合わせて切り替わります。

## ダウンロードと入れ方

[Releases](https://github.com/guribow/clip-history/releases/latest) から zip をダウンロードしてください。`ClipHistory-<版>-ja.zip` には日本語の説明書、`-en.zip` には英語の説明書が入っています。アプリはどちらも同じです。

1. zip を開き、ClipHistory.app を「アプリケーション」フォルダへ移します。
2. ダブルクリックすると「開けませんでした」という警告が出るので、「完了」で閉じます。App Store 以外のアプリなので、最初の 1 回だけ出ます。
3. システム設定の「プライバシーとセキュリティ」を開き、下のほうにある「このまま開く」を押してパスワードを入れます。
4. もう一度ダブルクリックして、「開く」を押します。
5. 選ぶだけで貼れるように、システム設定の「プライバシーとセキュリティ」→「デバイスの制御とデータへのアクセス」で ClipHistory をオンにします。一覧にないときは「＋」で追加します。macOS 26 以前では、この項目の名前は「アクセシビリティ」です。

メニューバーにクリップボードのアイコンが出たら準備完了です。新しいバージョンに入れ替えたときは、「デバイスの制御とデータへのアクセス」の ClipHistory を「−」でいったん外してから、もう一度オンにしてください。zip から入れ替えたときは、その前に 2〜4 ももう一度行ってください。メニューの「アップデート」で入れ替えたときは、2〜4 は要りません。

## 使い方

- **残す**：ふつうにコピーするだけです。テキストと画像が、新しい順に 200 件まで残ります。
- **貼る**：⇧⌘V で一覧を出し、↑↓ で選んで Return を押します。ダブルクリックや、⌘1〜⌘9 でも貼れます。
- **探す**：一覧を出して文字を打つと、テキストを絞り込めます。
- **中身を見る**：一覧の行にマウスを置くか、右クリックすると、長い文の全文や画像を大きく見られます。メニューバーのアイコンの履歴でも、カーソルを合わせると全文が出ます。
- **消す**：一覧で選んで ⌘⌫ を押すか、右クリックで「削除」を選ぶと、1 件消せます。すべて消すときは、メニューバーのアイコンから「履歴をすべて消去…」を選びます。
- **一時停止**：人に見せたくないものをコピーするときは、メニューバーのアイコンから「記録を一時停止」を選びます。
- メニューバーのアイコンからも、最近の 10 件を選んで貼れます。
- 「設定…」で、ショートカットキー、残す件数、ログイン時に起動を変えられます。
- 新しいバージョンが出ると、メニューバーのアイコンに小さな丸が付きます。メニューの一番上の「バージョン … にアップデート…」を選ぶと、入れ替えて起動し直します。

## 履歴とデータについて

- パスワード管理アプリなどが「保存しないで」と印を付けたものは残しません。
- 「デバイスの制御とデータへのアクセス」をオンにしていないときは、選んだものがクリップボードに入るだけです。⌘V で貼ってください。
- 履歴は `~/Library/Application Support/ClipHistory` に保存します。履歴を外部に送ることはありません。
- アップデートの確認のため、1 日 1 回 GitHub に最新のバージョンを問い合わせます。確認は、メニューの「アップデートを自動で確認」で止められます。それ以外にデータを外部に送ることはありません。

## 消し方

1. メニューバーのアイコン →「終了」
2. ClipHistory.app をゴミ箱に入れます。
3. 履歴も消すときは、`~/Library/Application Support/ClipHistory` をゴミ箱に入れます。

## ソースからビルドする

Xcode（swiftc）が必要です。

```bash
./build.sh   # ビルドして ~/Applications/ClipHistory.app に入れる
./dist.sh    # dist/ に配布用の zip を作る
./test.sh    # 中身のしくみを確かめる
```
